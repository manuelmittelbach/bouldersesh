Pill-shaped filter / selection chip — feed filter bar, level pickers.

```jsx
<Chip active icon={<i data-lucide="map-pin" />} trailingIcon={<i data-lucide="chevron-down" />}>
  Boulderwelt München
</Chip>
<Chip icon={<i data-lucide="calendar" />}>Heute & morgen</Chip>
```

`active` fills the chip with ink (rock-900). Pass `icon` / `trailingIcon` as nodes. Use `as="div"` for non-interactive display chips.
