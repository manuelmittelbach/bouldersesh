Round, single-icon tap target for headers, nav and inline actions.

```jsx
<IconButton label="Zurück" variant="ghost"><i data-lucide="arrow-left" /></IconButton>
<IconButton label="Senden" variant="brand"><i data-lucide="send" /></IconButton>
```

Variants: `ghost` (header) · `soft` (on canvas) · `brand` (orange, e.g. chat send) · `ink` (dark). Sizes `sm`/`md`/`lg` (36–44px). Always pass `label` for a11y.
