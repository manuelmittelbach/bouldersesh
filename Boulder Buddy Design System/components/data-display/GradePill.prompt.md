Climbing-grade chip — mono numerals on a muted level-coloured surface. The signature data element of the feed.

```jsx
<GradePill grade="6a – 6c" band="intermediate" />
<GradePill grade="7a+" band="advanced" />
<GradePill grade="5+ – 6a" band="beginner" size="sm" />
```

Bands map to skill level: `beginner` (green) · `intermediate` (blue) · `advanced` (orange) · `pro` (red) · `neutral`. Always uses JetBrains Mono so grades read as data.
