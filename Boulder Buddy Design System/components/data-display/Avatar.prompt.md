Initials avatar with a calm, cool tone set (no candy gradients) and optional online dot.

```jsx
<Avatar name="Lina Kessler" tone="orange" size="md" online />
<Avatar initials="M" tone="rock" size="xl" />
```

Sizes `xs`–`xl` (28–88px). Tones: `rock` (default), `orange`, `slate`, `moss`, `clay`. Pass `src` for a photo. Initials use the display face (Space Grotesk).
