Small status marker with optional icon — verification, request state, match hints.

```jsx
<Badge tone="success" icon={<i data-lucide="check-circle-2" />}>Verifiziert</Badge>
<Badge tone="warning" icon={<i data-lucide="clock" />}>Wartet</Badge>
<Badge tone="brand">1 / 2 Plätze frei</Badge>
```

Tones: `neutral` · `success` · `warning` · `danger` · `brand`. Keep copy to 1–3 words.
